### 🧬 HealthIQ — AI-based Lab Report Analysis System *(April 2026)*
> A privacy-first AI system for analyzing lab reports and tracking health trends — fully offline, no cloud data exposure.

- 📄 PDF lab report extraction & analysis using LLMs (Llama3 via Ollama)
- 📊 Trend tracking for health metrics with ICMR/WHO abnormality detection
- 🔌 REST APIs via FastAPI + interactive dashboard with Streamlit & Plotly
- **Stack:** Python · FastAPI · MongoDB · Streamlit · Plotly · Llama3 · Pandas

- **Stack:** Python · Node.js · MySQL · React.js · HTML · CSS · JavaScript
